# Legacy Gryphon prototype

This directory preserves the original `Gryphon_new` branch snapshot for behavioral and configuration reference only.

It is not the active runtime implementation. The maintained engine, simulations, tests, tuning targets, reelsets, and renderer assets live at the repository root.

The legacy snapshot is intentionally retained because it contains the original mechanics document, standalone feature-flow prototypes, tuning records, generated workbook, and supporting reference material used during integration.
